適合什麼場合

社群要做決定

社團、學校、社區、合作社：「接下來一年最該做什麼？」比起投票表決，先看清楚大家的想法分布。

開會前先收意見

把爭點和共識在會前攤開，會議時間直接花在真正有分歧的地方。

工作坊現場

20–50 人掃 QR code 即投，15 分鐘就能一起看意見地圖，接著分組討論。

一場討論怎麼進行

  1. 準備：訂一個開放式題目，寫 8–15 句「種子意見」，一句一個想法，大家可以同意或不同意。
  2. 發連結：打開連結就能投票，不用註冊，想到什麼也可以隨時丟出來。
  3. 看地圖：結果頁即時更新，想法相近的人會靠在一起、自動分成幾群；系統也會找出每群的代表意見，還有大家都同意的部分。
  4. 收尾：和大家一起讀地圖，先看共識、再看分歧；需要的話下載完整資料（匿名化 CSV）。

主持技巧、種子意見怎麼寫、要多少人：都在實務指南。

常見問題

真的不用架伺服器嗎？

對。「無伺服器」的意思是：沒有一台你需要照顧的機器。不用租主機、不用備份資料庫、不用半夜重開機。程式放在 Cloudflare 的雲端服務上，有人投票才運轉，平常不耗資源也不收費。完整的技術說明（包括我們比較過哪些替代方案）在這份文件。

MCP 要怎麼用？

MCP 是給 Codex、Claude 等 AI 助手使用的連接方式。一般參與或主持討論不需要設定；想讓 AI 直接建立場次、讀取即時結果或協助綜整時，才需要把 Pocket Polis 的 MCP 端點加進 AI 助手。端點不是網頁，不用在瀏覽器打開。

# Codex
codex mcp add pocket-polis --url https://polis.mashbean.net/mcp

# Claude Code
claude mcp add --transport http pocket-polis https://polis.mashbean.net/mcp

設定一次後，直接告訴 AI 場次網址或 10 碼場次 ID，例如：「讀取這場討論，整理各群立場、跨群共識和主要分歧，並附上意見編號。」讀取指定場次的公開結果不需要金鑰；管理場次或匯出非公開資料時，才需要該場討論的管理金鑰。自架者請把網址換成自己的網域。完整工具與權限說明見 MCP 文件。

參與的人會被記名嗎？

不會。不用註冊、不填 email；瀏覽器只保存一個隨機代號避免重複計票。結果頁和下載的資料裡都沒有任何身分資訊。提醒：這種輕量做法擋不住刻意的灌票，適合彼此有基本信任的社群、課堂、工作坊；高對抗性的公共諮詢請用官方 pol.is。

需要多少人參加才有意義？

4 人以上（每人投滿門檻票數）就會開始分群；20 人以上地圖趨於穩定。系統設計上支撐到數百至上千人。

它和官方 pol.is 有什麼不同？

官方 pol.is 是成熟的大型平台，需要工程團隊自架或申請使用。Pocket Polis 依公開文獻重新實作同一套分群方法（並用官方公開資料驗證過，三個資料集的分群一致性 ARI 0.78–0.86），換來「一鍵發起、免費跑」的輕量性。與官方團隊（The Computational Democracy Project）無隸屬關係。

資料存在哪裡？可以帶走嗎？

存在部署者的 Cloudflare 帳號裡，每場討論各自獨立。主持人隨時可以下載完整的意見清單與投票紀錄（匿名化 CSV），也可以選擇開放任何人下載。

示範站有使用規範嗎？

有。出現騷擾、仇恨言論、違法內容、洩露個資、灌票操弄等情況時，站方（mashbean）有權下架相關討論，詳見行為準則。自架的站點由部署者自訂規範。
